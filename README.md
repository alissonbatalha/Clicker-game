# 🎮 Click Empire

Um jogo de clicker viciante feito com React. Clique rápido, compre upgrades e construa seu império!

## 🎮 Características

- Sistema de clique manual progressivo
- 3 tipos de upgrades (2x Power, Auto-clicker, Mega Click)
- Sistema de níveis com multiplicador dinâmico
- Auto-gerador de pontos
- Interface intuitiva com gradient moderno
- Fully responsivo

## 🚀 Como Usar

### Requisitos
- Node.js 14+
- npm ou yarn

### Instalação

git clone https://github.com/alissonbatalha/click-empire.git
cd click-empire
npm install

### Executar Localmente

npm run dev

Acesse http://localhost:5173

### Build para Produção

npm run build

### Deploy Vercel

npm install -g vercel
vercel

### Deploy GitHub Pages

npm run build
Depois fazer upload da pasta 'dist' no GitHub Pages nas configurações do repositório.

## 🎨 Tecnologias

- React 18
- Vite
- CSS-in-JS

## 📝 Como Jogar

1. Clique no botão grande para ganhar pontos
2. Compre upgrades para aumentar sua produção
3. 2x Power - aumenta dano do clique (50 pts)
4. 🤖 Auto+1 - ganha 1 ponto por segundo (100 pts)
5. 💥 Mega - bonus de 1000 pontos (500 pts)
6. Suba de nível para aumentar o multiplicador
7. Quanto mais upgrade, mais rápido cresce!
